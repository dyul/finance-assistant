## 롤백

이 앱은 현재 DB, 서버 마이그레이션과 사용자 계정이 없는 정적 브라우저 앱입니다. 롤백 시 거래 원본의 서버 복구 작업은 없습니다.

- [ ] 직전 정상 배포의 커밋과 배포 식별자 확인
- [ ] 호스팅 서비스에서 직전 정상 배포로 되돌리기
- [ ] 코드 수정으로 복구할 때는 공유 이력을 덮어쓰지 않고 문제 커밋을 `git revert`하는 것을 기본으로 검토
- [ ] 샘플 업로드와 핵심 결과로 복구 확인
- [ ] 문제 배포에서 생성된 브라우저 설정 형식 변경 여부 확인
- [ ] 사용자에게 영향 범위와 우회 방법 안내
- [ ] 원인과 재발 방지 테스트를 변경 기록에 남기기
