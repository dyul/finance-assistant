# Finance Assistant Beta 테스트 방법

## 1. 테스트 목적

서비스를 처음 사용하는 개인사업자가 별도 설명 없이 Finance Assistant의 목적과 사용 방법을 이해하고, 샘플 또는 본인의 거래내역 Excel·CSV로 핵심 결과를 확인할 수 있는지 알아봅니다.

이 테스트는 제품 사용성을 확인하기 위한 것이며 회계·세무 검토나 미래 잔액의 정확성을 보장하기 위한 검증이 아닙니다. 전망은 업로드한 과거 거래 패턴을 바탕으로 한 추정치입니다.

## 2. 테스트 방법

사용자에게 세부 사용법을 먼저 설명하지 않고 production URL만 전달하는 것을 기본으로 합니다. 사용자가 막힐 때만 최소한의 도움을 제공합니다.

앱 안에는 아직 확정된 피드백 URL이나 이메일이 없습니다. 테스트 초대자는 URL을 전달할 때 답변을 받을 외부 채널을 함께 안내해야 합니다. 사용할 채널은 **확인 필요**입니다.

### 첫 참가자 모집 기준

초기에는 3~5명을 모집합니다. 개인사업자·소규모 사업 운영자 중 사업 통장 거래내역을 Excel로 받을 수 있고, 별도 ERP·자금관리 시스템이 없거나 사용 빈도가 낮은 사람을 우선합니다. 사업 현금 입출금을 직접 관리하며 업무에서 Excel을 사용하는 비회계 전문가도 포함할 수 있습니다.

복잡한 연결·법인 회계, 다계좌 통합, 회계·세무 신고 또는 10MB 초과 파일이 필수인 사용자는 이번 초기 테스트에서 제외하는 것을 권장합니다. 이는 모집 기준이며 앱 기능으로 구현하지 않습니다.

### 운영 원칙

사용자가 막혀도 바로 사용법을 알려주지 않고 먼저 막힌 위치와 실제 행동을 기록합니다. 첫 화면 이해, Excel 선택, 샘플 또는 자기 파일 사용, 업로드 망설임, 처음 확인한 숫자, Forecast·예상 범위·자금 부족 이해, PDF 필요, 오류 복구와 재사용 이유를 관찰합니다.

## 3. 권장 테스트

- 샘플 Excel과 샘플 CSV로 각각 테스트
- 본인이 사용하는 거래내역 Excel 또는 CSV로 테스트
- 현재 현금 상태와 향후 3개월 전망 확인
- 예상 범위(보수·기준·낙관) 변경
- 필요하면 확정 예정 거래 추가
- PDF 저장 또는 인쇄 결과 확인

본인의 파일을 사용할 때는 신뢰할 수 있는 기기에서 진행합니다. 앱은 파일을 현재 브라우저에서 분석하지만, 공용 기기에서는 테스트 후 브라우저 사이트 데이터를 지우는 것을 권장합니다.

## 4. 사용자에게 물어볼 질문

질문을 읽어주되 답을 예시로 먼저 제시하지 않습니다.

1. 처음 화면을 보고 어떤 서비스라고 생각했나요?
2. 어떤 Excel을 올려야 하는지 바로 알 수 있었나요?
3. 업로드하면서 개인정보가 걱정됐나요?
4. 가장 먼저 본 숫자는 무엇인가요?
5. 이해하기 어려운 숫자나 표현이 있었나요?
6. 향후 3개월 전망을 어느 정도 신뢰할 수 있다고 느꼈나요? 그렇게 느낀 이유는 무엇인가요?
7. 예상 범위(보수·기준·낙관)의 의미를 어떻게 이해했나요?
8. 실제 자금 관리에 도움이 될 것 같은 기능은 무엇인가요?
9. 필요 없다고 느낀 기능은 무엇인가요?
10. 사용하면서 막힌 부분은 어디였나요?
11. 다시 사용할 의향이 있나요? 그 이유는 무엇인가요?
12. 비용을 지불한다면 어떤 기능 때문에 지불할 것 같나요?

## 5. 문제를 제보할 때

문제는 [`BETA_ISSUE_TEMPLATE.md`](./BETA_ISSUE_TEMPLATE.md)에 기록합니다.

기본적으로 공유해도 되는 정보는 사용 브라우저, 파일 확장자, 대략적인 파일 크기와 행 수, 파일의 컬럼 구조, 화면에 표시된 오류 종류입니다.

다음 정보는 기본적으로 공유하지 않습니다.

- 실제 거래 적요와 거래 상대방
- 계좌번호
- 실제 금액과 잔액
- 전체 거래내역이나 원본 Excel·CSV 파일

스크린샷이 필요하면 실제 금융정보를 가린 뒤 공유합니다. 원본 파일 제출은 기본 절차가 아니며 자동으로 수집하거나 전송하지 않습니다.

## 6. Beta 초대 메시지 필수 요소

저장소에는 실제 production URL과 피드백 채널이 없으므로 임의의 주소나 이메일을 문서에 넣지 않습니다. 초대자는 메시지에 다음을 포함합니다.

- 아직 사용자 검증 중인 Beta 서비스라는 점
- 실제 production URL
- 먼저 별도 설명 없이 사용해달라는 요청
- 샘플 또는 본인의 거래내역 Excel·CSV를 사용할 수 있다는 안내
- 원본 파일은 외부 분석 서버로 전송되지 않는다는 안내
- 오류 제보 시 원본 금융정보나 Excel·CSV를 보내지 말아야 한다는 안내
- 사용 후 짧은 피드백을 받을 실제 외부 채널
