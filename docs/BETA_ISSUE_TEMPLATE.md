## 개인정보 확인

- [ ] 실제 계좌번호를 기록하지 않았습니다.
- [ ] 실제 거래 상대방이나 거래 적요를 기록하지 않았습니다.
- [ ] 실제 금액과 잔액을 기록하지 않았습니다.
- [ ] 전체 거래내역을 복사하지 않았습니다.
- [ ] 원본 Excel을 첨부하거나 보관하지 않았습니다.
- [ ] 스크린샷이 있다면 금융정보를 가렸습니다.
