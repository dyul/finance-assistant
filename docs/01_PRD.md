# Finance Assistant PRD 안내

이 파일은 프로젝트 초기 아이디어 문서였으며 현재 구현 범위와 맞지 않는 AI·범용 재무 분석 표현을 포함하고 있었습니다.

Day 29부터 제품 정의, 대상 사용자, 기능 패키지, 한계, 개인정보 구조, 가격 가설과 출시 기준의 기준 문서는 [PRODUCT.md](./PRODUCT.md)입니다.

현재 제품의 핵심 범위는 다음과 같습니다.

> 통장 거래내역 Excel을 업로드하면 최근 입출금 흐름을 분석하고 향후 3개월 예상 잔액과 자금 부족 가능성을 확인할 수 있는 개인사업자·소규모 사업자용 MVP Beta.

Finance Assistant는 정확한 미래 보장, 회계 업무 전체 자동화 또는 세무 판단을 제공하지 않습니다.
