# Finance Assistant PRD

## 1. Vision

Finance Assistant는 사용자가 기존에 사용하던 재무 엑셀을 업로드하면,
AI가 파일 구조를 이해하고 표준화하여 자동으로 재무 분석을 수행하는 AI Copilot이다.

---

## 2. Problem

현재 개인사업자와 중소기업은

- 엑셀 양식이 제각각이다.
- ERP가 없거나 체계적이지 않다.
- 재무 데이터를 해석하기 어렵다.
- 보고서를 만드는 데 많은 시간이 소요된다.

---

## 3. Solution

사용자는 기존 엑셀을 그대로 업로드한다.

↓

AI가

- 파일 유형을 인식하고
- 컬럼을 자동 매핑하며
- 데이터를 표준화한다.

↓

Finance Assistant가

- KPI 계산
- 재무 분석
- AI 인사이트
- 보고서 생성

까지 자동 수행한다.

---

## 4. Target Customer

### Primary

- 개인사업자
- 1인 사업자
- 프리랜서

### Secondary

- 중소기업
- 스타트업
- 관리회계 담당자

---

## 5. Core Value

사용자가 엑셀을 수정하는 것이 아니라,
AI가 사용자의 엑셀을 이해한다.
