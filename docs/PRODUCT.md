# Finance Assistant 제품 정의서

> 상태: MVP Beta 제품 가설  
> 기준 범위: Day 1~42 구현 상태
> 주의: 이 문서의 무료·유료 구분과 가격 모델은 사용자 검증 전 내부 가설이며 확정 정책이 아닙니다. 현재 앱에서는 구현된 모든 기능을 제한 없이 사용할 수 있습니다.

## 1. Product Overview

Finance Assistant는 통장 거래내역 Excel 또는 CSV를 보유하고 있지만 앞으로의 자금 부족을 체계적으로 관리하기 어려운 개인사업자와 소규모 사업자를 위한 브라우저 기반 현금흐름 분석 도구다.

통장 거래내역 Excel 또는 CSV를 업로드하면 최근 입출금 흐름을 정리하고, 과거 반복 거래와 최근 수입 추세를 바탕으로 향후 3개월 예상 잔액과 자금 부족 가능성을 보여준다. 이 결과는 미래를 보장하는 예측이나 회계 보고서가 아니라 단기 자금계획을 돕는 추정치다.

## 2. Target User

### Primary user

통장 거래내역 Excel은 있지만 향후 자금 부족을 체계적으로 관리하지 못하는 개인사업자 또는 소규모 사업자.

다음 상황에 특히 적합하다.

- 통장 입출금 내역은 Excel로 내려받을 수 있다.
- 이번 달 잔액은 알지만 1~3개월 뒤 부족 가능성은 계산하지 않는다.
- 반복되는 매출·월세·공과금과 확정된 예정 입출금을 함께 보고 싶다.
- ERP나 전문 자금관리 시스템을 도입하기에는 업무 규모가 작다.

현재 MVP는 모든 기업, 복잡한 법인 회계, 세무 신고 또는 관리회계 전반을 대상으로 하지 않는다.

## 3. User Problem

- 거래내역 Excel 양식이 은행과 사용자마다 달라 분석을 시작하기 어렵다.
- 입금·출금 합계는 볼 수 있어도 향후 월말 잔액을 직접 계산하기 번거롭다.
- 자금 부족이 예상될 때 부족 기간, 최저 잔액과 필요한 현금 여유를 빠르게 알기 어렵다.
- 누락 날짜, 잘못된 금액과 자동 인식 오류가 조용히 잘못된 숫자를 만들 수 있다.
- 민감한 금융 거래 원본을 외부 서버에 올리는 데 부담을 느낄 수 있다.

## 4. Core Value Proposition

> 통장 거래내역 Excel을 업로드하면 최근 입출금 흐름을 분석하고 향후 3개월 예상 잔액과 자금 부족 가능성을 확인할 수 있습니다.

제품이 약속하는 범위는 다음과 같다.

- 다양한 거래내역 Excel을 가능한 범위에서 자동 인식한다.
- 확실하지 않은 데이터는 임의의 0원으로 만들지 않고 오류나 제한을 알린다.
- 과거 반복 패턴을 이용한 향후 3개월 추정치를 제공한다.
- 사용자가 확정 예정 거래와 예상 범위를 바꿔 단기 자금계획을 검토할 수 있게 한다.

제품은 정확한 미래 보장, 회계 업무 전체 자동화, 세무 판단 또는 자금 부족의 완전한 방지를 약속하지 않는다.

## 5. Current MVP Features

### A. Core

- `.xlsx`·`.xls`·`.csv` 거래내역 업로드와 브라우저 내 분석
- 거래 시트와 헤더 자동 탐지
- 입금·출금, 금액·거래구분, 부호형 금액 컬럼 인식
- 날짜와 금액 정규화, 거래 자동 분류
- 전체 입출금과 월별·분기별·연도별 과거 순현금흐름 집계
- 과거 실제 잔액과 선택한 향후 3개월 예상 잔액을 한 화면에서 비교하는 SVG 추이 그래프
- 최근 유효 잔액 확인
- 잔액 컬럼이 없는 파일의 세션 전용 현재 잔액 직접 입력
- 반복 거래 탐지와 최근 수입 추세를 반영한 향후 3개월 전망
- 파일의 유효한 미래 날짜 거래를 과거 실적과 분리해 현재 3개월 Forecast에 자동 반영
- 최저 예상 잔액, 자금 부족 예상 기간과 필요한 현금 여유 계산
- 데이터 품질 확인과 분석 제외 사유 안내

### B. Differentiator

- 보수·기준·낙관 예상 범위 비교
- 확정 예정 거래를 세 예상 범위에 동일하게 반영
- 파일 미래 거래의 출처·적용 범위·개별 포함 여부 확인
- 상황, 근거와 권장 행동을 구분한 추천 액션
- 자동 인식 실패 또는 오인식 시 직접 설정
- 중복 컬럼, 오류 금액과 유효 거래 부족에 대한 명시적 복구 안내
- 원본 행 순서가 아닌 정규화 날짜 기준 분석

### C. Convenience

- 처음 사용자를 위한 온보딩과 샘플 Excel·CSV
- 인쇄 또는 PDF 저장용 분석 리포트
- 파일명 기준 선택 예상 범위·확정 예정 거래 브라우저 저장
- 직접 입력 잔액의 비저장·Forecast 시작 잔액 전용 처리
- 반응형 3개월 전망 카드와 핵심 결과 요약
- 분석에 사용된 거래, 기간 단위 과거 흐름과 지출 구성 확인
- 월·분기별 최근 12개 기간 기본 표시와 전체 기간 보기·접기

### D. Advanced / Future

다음 항목은 현재 구현되지 않은 향후 후보 기능이다.

- 복수 계좌와 복수 파일 통합
- 3개월을 넘는 장기 전망
- 사용자 정의 예상 범위와 가정값
- 프로젝트 저장과 과거 분석 비교
- 팀 공유와 권한 관리
- 자금 부족 자동 알림
- 금융기관 자동 연동
- 서버 동기화 또는 계정 기반 백업

## 6. Free / Pro Hypothesis

이 구분은 MVP 사용자 검증을 위한 가설이다. 현재 앱에는 결제, 사용량 제한, paywall 또는 기능 차단이 없으며 모든 구현 기능을 계속 사용할 수 있다.

| 무료 가설 | Pro 후보 가설 |
|---|---|
| Excel 1개 분석 | 보수·낙관 예상 범위 |
| 기본 현금흐름 집계 | 확정 예정 거래 관리 |
| 기준 향후 3개월 전망 | PDF 리포트 |
| 데이터 오류 확인 | 파일별 설정 저장 |
| 자동·수동 컬럼 매핑 | 고급 추천 액션 |
| 샘플 Excel·온보딩 | 향후 복수 파일·계좌 통합 |

검증해야 할 핵심 질문은 “사용자가 반복해서 해결하려는 문제는 무엇이며, 어떤 기능이 실제 의사결정 시간을 줄이는가?”이다. 단순히 구현 난도가 높다는 이유만으로 유료 기능을 결정하지 않는다.

## 7. Out of Scope

현재 제품 범위에 포함하지 않는다.

- 결제, 구독과 사용량 제한
- 로그인, 회원가입과 사용자 계정
- DB, 서버 저장과 클라우드 동기화
- 세무 신고, 회계 장부 또는 법정 재무제표 작성
- 금융·회계 전문가의 판단 대체
- 은행 API 자동 연동
- 이메일·메신저 알림
- 개인 금융 거래 원본을 이용한 분석 데이터 수집

## 8. Known Limitations

- 전망 기간은 향후 3개월로 제한된다.
- 전망은 과거 반복 거래 패턴과 최근 수입 추세에 기반한 추정치다.
- 실제 입출금 시점과 금액이 달라지면 결과도 달라질 수 있다.
- 자동 시트·컬럼 탐지가 실패하면 사용자가 직접 설정해야 한다.
- Excel·CSV 파일은 최대 10MB까지 지원한다.
- 자동 헤더 탐지는 30행까지, 직접 설정은 100행까지 지원한다. 101행 이후 헤더는 지원하지 않는다.
- 대형 파일은 브라우저 메모리와 상세 화면 렌더링 성능의 영향을 받는다.
- CSV는 쉼표 구분, UTF-8·UTF-8 BOM과 브라우저가 지원하는 CP949/EUC-KR을 지원하며 세미콜론·탭 구분은 지원하지 않는다.
- CSV 숫자 문자열은 Excel 날짜 일련번호로 해석하지 않는다.
- 같은 파일명은 선택 예상 범위와 확정 예정 거래 설정이 공유될 수 있다.
- 파일 미래 거래는 현재 3개월 Forecast 범위 안에서만 반영되며 기간 밖 거래는 다음 분석에서 다시 범위를 확인해야 한다.
- 파일 미래 거래의 개별 제외 상태는 저장하지 않아 새 파일이나 같은 파일 재업로드에서 기본 자동 반영 상태로 초기화된다.
- 기간별 집계는 거래가 존재하는 calendar 월·분기·연도만 표시하며 날짜 오류 거래와 미래 source 거래는 제외한다.
- 기간말 잔액은 파일에서 해당 기간 내 마지막으로 확인된 거래 잔액이며, 잔액이 없을 때 직접 입력 잔액으로 과거 값을 역산하지 않는다.
- 잔액 추이 그래프는 월별 기간말 잔액만 사용하며 `null` 잔액과 거래가 없는 월을 관측 공백으로 유지한다.
- 직접 입력 잔액은 그래프의 Forecast 시작점으로만 사용하고, 미래 선은 현재 선택된 scenario의 기존 Forecast 월말 잔액을 사용한다.
- 수식 셀은 Excel 파일에 저장된 cached result에 의존하며 수식을 직접 실행하지 않는다.
- 분석은 현재 브라우저에서만 수행한다.
- 계정, 클라우드 저장과 여러 기기 간 동기화가 없다.
- 반복 거래로 판단할 자료가 부족하거나 최근 잔액도 직접 입력 잔액도 없으면 향후 전망 일부를 제공할 수 없다.

## 9. Privacy Architecture

현재 코드 기준으로 업로드한 Excel·CSV 거래내역을 외부 서버로 전송하는 API, 분석 서버 또는 analytics SDK가 없다.

- 원본 파일은 현재 브라우저 메모리에서 읽고 분석한다.
- 원본 거래내역과 계산된 분석 결과는 브라우저 저장소에 저장하지 않는다.
- 선택 예상 범위와 확정 예정 거래는 파일명을 기준으로 브라우저 `localStorage`에 저장될 수 있다.
- 직접 입력한 현재 잔액은 과거 거래 분석에 합치지 않고 현재 세션의 Forecast 시작점으로만 사용하며 `localStorage`에 저장하지 않는다.
- 파일 미래 거래의 Forecast 제외 상태도 현재 세션에서만 유지하고 `localStorage`에 저장하지 않는다.
- 같은 파일명을 사용하는 다른 파일은 이 설정을 공유할 수 있다.
- 인쇄·PDF 저장은 사용자의 브라우저 인쇄 기능을 사용한다.

앱 내 신뢰 문구는 반드시 “서버로 전송하지 않고 현재 브라우저에서 분석”한다는 현재 구현 범위와 함께, 일부 설정은 브라우저에 저장될 수 있다는 예외를 같이 설명해야 한다.

## 10. Future Roadmap

### 검증 우선

- 실제 개인사업자 파일로 자동 분석 성공률과 오류 복구 이해도 확인
- 향후 3개월 전망과 필요한 현금 여유가 실제 자금계획에 도움이 되는지 확인
- 반복 사용 이유와 무료·유료 경계 검증

### 제품 개선 후보

- 대용량 상세 거래 가상 스크롤
- 동일 파일명 설정 충돌을 줄이는 안전한 파일 식별 방식
- 분석 프로젝트 저장과 이전 결과 비교
- 복수 파일·계좌 통합
- 장기·사용자 정의 전망
- 팀 공유와 자금 부족 알림

구현 순서는 사용자 검증 결과를 근거로 결정한다.

## 11. Pricing Hypothesis

금액은 외부 시장조사와 지불 의향 검증 전에는 정하지 않는다. 시장 평균가나 경쟁사 가격을 추정해 사실처럼 사용하지 않는다.

검토할 모델은 다음과 같다.

1. 1회 분석형: 특정 파일 또는 리포트 1회 분석에 과금하는 가설
2. 월 구독형: 반복 사용, 설정 저장과 지속적인 계획 검토에 과금하는 가설
3. 파일·프로젝트 단위: 여러 분석 프로젝트를 관리하는 사용자에게 과금하는 가설
4. 무료 + Pro: 기본 분석은 무료로 제공하고 반복 계획 기능을 Pro로 묶는 가설

각 모델은 결제 의향, 사용 빈도와 사용자가 가치 있다고 말한 기능을 확인한 뒤 비교한다. 현재 결론은 “시장 검증 필요”다.

## 12. Release Criteria

MVP Beta를 실제 사용자에게 전달하기 전 최소 기준이다.

- 전체 자동 테스트, lint와 production build 통과
- 대표 정상·부분 오류·분석 불가 Excel의 브라우저 업로드 확인
- 오류 데이터가 임의의 0원으로 재무 합계에 포함되지 않음
- 자동 분석 실패 시 직접 설정과 해결 방법 제공
- 전망·위험·추천 액션에서 “예상·추정” 표현 유지
- 개인정보 문구와 실제 네트워크·저장 구조 일치
- 알려진 한계와 지원 파일 범위를 사용자가 찾을 수 있음
- 모바일·데스크톱 핵심 흐름에서 치명적 UI 깨짐 없음
- 사용자 테스트 피드백과 치명적 문제 대응 경로 준비

## 13. MVP 사용자 테스트 지표 계획

아직 analytics 코드를 추가하지 않는다. 초기에는 사용자 동의하에 관찰·인터뷰와 익명 집계로 검증하고, 개인 금융 거래 원본·적요·금액·잔액은 분석 지표로 수집하지 않는 방향을 유지한다.

초기 3~5명 결과는 비율만 제시하지 않고 분자·분모와 관찰 내용을 함께 기록한다. 작은 표본을 시장 전체 성과나 통계적으로 검증된 결과로 확대 해석하지 않는다.

- 첫 방문 → Excel 업로드 전환율
- 샘플 Excel 다운로드 비율
- 자동 분석 성공률
- 직접 설정 사용률과 복구 성공률
- blocking·partial warning 발생률
- 향후 3개월 전망 확인률
- 예상 범위 변경률
- 확정 예정 거래 추가율
- PDF 저장 사용률
- 재방문율
- “이 결과가 실제 자금계획에 도움이 됐는가” 응답
- 가장 이해하기 어렵거나 신뢰하기 어려웠던 화면

## 14. 초기 사용자 테스트 질문

1. 첫 화면만 보고 이 서비스가 무엇을 하는지 이해했나요?
2. 어떤 Excel을 올려야 하는지 이해했나요?
3. 업로드 후 가장 먼저 본 숫자는 무엇이었나요?
4. 향후 3개월 전망이 추정치라는 점을 이해했나요?
5. 보수·기준·낙관 예상의 차이를 이해했나요?
6. 필요한 현금 여유 금액이 실제 자금계획 결정에 도움이 되나요?
7. 오류나 분석 중단이 발생했을 때 원인과 해결 방법을 이해했나요?
8. 확정 예정 거래를 어떤 상황에서 추가할 것 같나요?
9. PDF 리포트를 보관하거나 공유할 것 같나요?
10. 한 달 뒤 다시 사용할 이유가 있나요?
11. 비용을 지불한다면 어떤 기능이나 결과 때문인가요?
12. 이 결과를 신뢰하기 위해 추가로 필요한 설명은 무엇인가요?

## 15. 판매용 한 줄 설명 후보

아래 문구는 확정 마케팅 카피가 아니라 사용자 테스트 후보이다.

1. 통장 거래내역 Excel만 올리면 3개월 뒤 자금 상황을 미리 확인합니다.
2. 이번 달 잔액이 아니라, 앞으로 부족할 수 있는 돈을 확인하세요.
3. 개인사업자를 위한 간단한 향후 3개월 현금흐름 전망 도구.
